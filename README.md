# גיבורי המוקד

משחק RTL לילדים בעברית: מקשיבים לדיווחים דמיוניים, בוחרים פעולה בטוחה ולומדים לשתף מבוגרים אחראיים. אין במשחק תרחישים, מיתוג או עצות מבצעיות של משטרה.

## הפעלה

```bash
npm install
npm run dev
```

## בדיקה ובנייה

```bash
npm test
npm run build
```

## התקנה ב-Windows

האתר כולל PWA: פותחים את כתובת ה־`preview` בדפדפן Chromium ובוחרים Install app מתפריט הדפדפן. לחבילת שולחן עבודה:

```bash
npm run dist:win
```

הפקודה בונה את ה־PWA ומייצרת מתקין Electron בתיקיית `release/` (Windows דורש הרצה על Windows או CI עם `--win`). הפקודה משתמשת ב־`--publish never`, כך שבנייה מקומית לא תלויה בהגדרת ספק עדכונים.

המתקין כולל את תיקיית `dist` בתוך האפליקציה. פותחים את קובץ ה־`.exe` שנוצר
מתיקיית `dist/`; אין לפתוח את `index.html` מתוך תיקיית המקור במקום להריץ את
המתקין. כתובות ה־assets נבנות כנתיבים יחסיים כדי שה־renderer יעבוד גם מתוך
`file://` של Electron וגם בשרת HTTP.

במקרה חירום אמיתי פונים למבוגר שסומכים עליו ולשירותי החירום המקומיים.
